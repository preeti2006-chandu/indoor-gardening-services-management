Indoor Gardening Services Management
Project Overview
The Indoor Gardening Services Management system is a ServiceNow application designed to manage indoor gardening service requests efficiently.

Objective
To provide a centralized system for customers to submit service requests and for technicians to process and manage those requests.

Key Features
Service request creation
Customer details management
Service type selection
Preferred service date
Priority management
Request status management
Technician assignment
Automated request processing using ServiceNow Flow Designer
Technology
ServiceNow
App Engine Studio
Flow Designer
Automation
A Flow Designer flow is configured to process newly created service requests and automatically update request details such as status and priority.

Project Status
Development and configuration completed.
